# Test plan: YOLO new tab (replica-test)

Build: branch `claude-chrome-extension-yolo`, package
`packages/chrome-extension-yolo` 0.2.0. Date: 2026-11-05.
Env: Windows 11, Bun 1.4.4, yolo-chromium CEF 156 shell
(Chromium 156.0.8078.80) with `--load-extension=<dist>`, fresh `--cache-path`,
seed data written by `scripts/capture.ts` (6 shortcuts, 4 past queries).

Playwright is not used (it needs npm); the same kind of checks run over the
DevTools protocol from Bun against the real shell. Selectors are ids, roles
and labels the page exposes.

How to run:

```sh
cd packages/chrome-extension-yolo
bun check && bun test                     # unit tests, 73 cases
bun run capture --exe=<yolo-chromium.exe> --out=../../docs/replica/ntp-search/clone-screens
```

`auto` column: `unit` = `bun test`; `cdp` = `scripts/capture.ts` in the
shell; `manual` = not automated, result is what was observed or `not run`.
