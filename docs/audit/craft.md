## Findings

| # | Severity | Finding | Evidence | Proposed patch |
|---|---|---|---|---|
| 1 | Medium | Studio pages (14 of 14 sub-pages) have no canonical link and no Open Graph/Twitter tags | crawl: canonical missing 14/15, og:title/og:image missing 14/15 | Emit canonical and og tags per studio in `C:\src\bun-os-archive\scripts\aphrody\tools\infra\craft-site.ts` (it already builds per-studio metadata near line 197), or add them to each `C:\src\yolo-ui\apps\*craft-web\web\index.html` (the home already has them) |
| 2 | Medium | 12 of 15 pages have no meta description (Lighthouse SEO 91 on /film/, /sound/, /cad/) | crawl; LH `meta-description` | Inject `<meta name="description">` from `craft-site.ts` (per-studio `description` at line 197) or add to each studio `web/index.html`; /effect/ and /light/ already have one |
| 3 | Medium | Home sends no Content-Security-Policy, Permissions-Policy or COOP | header probe on `GET /` | Reuse the CSP already defined in `C:\src\auto\apps\web\src\craft.ts` (`CSP` const, allows `wasm-unsafe-eval`) in the headers written by `craft-site.ts` (nginx/`_headers` snippet) or as a Cloudflare Transform Rule, plus `Permissions-Policy` |
| 4 | Low | 13 of 15 pages have no `<h1>` (only / and /film/ have one) | crawl h1Count | Add a visible or visually hidden `<h1>` to each studio `web/index.html` |
| 5 | Low | Brand inconsistency: home title "Craft by Aphrody: ..." and og:title "Craft: a space for your next idea"; studio titles "Aphrody / Bun · Images" | crawl titles | Pick one brand; change `<title>` in each studio `web/index.html` and og:title in `craft-site.ts` |
| 6 | Low | Home label-content-name-mismatch (a11y 0) and cache-insight 0 (`cache-control: no-cache` on all responses) | Lighthouse | Make visible link text match `aria-label`; add long-cache headers for hashed static assets |
| 7 | Low | /effect/ and /film/ a11y 87 | Lighthouse | Inspect Lighthouse a11y failures (raw report not stored; rerun with the tool) |
| 8 | Info | `/art/` Lighthouse run produced no result | tool log | Rerun; possibly page crash or timeout in headless without GPU. Not diagnosed |
| 9 | Info | No `security.txt` | 404 | Add `/.well-known/security.txt` (aphrody.com already serves one) |
