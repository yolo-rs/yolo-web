# WebAssembly Core & Component Model

WebAssembly (Wasm) is a binary code format designed for efficient execution and compact software representation. The Component Model extends Wasm to define composable, language-agnostic software components with the Canonical ABI.

## Architecture

- **Value Types**: `i32`, `i64`, `f32`, `f64`, `v128`, `funcref`, `externref`.
- **Component Model Types**: Rich types including `string`, `list`, `record`, `variant`, `result`, and resources (`own<T>`, `borrow<T>`).
- **Binary Structure**: 13 standard core sections from `custom` (0) to `data_count` (12).

## Loading Wasm Schemas

```typescript
import { StandardsLoader } from "@yolo-web/standards";

const loader = new StandardsLoader();
const wasm = await loader.loadWebAssembly();
console.log(`ValTypes: ${wasm.valTypes.join(", ")}`);
```
