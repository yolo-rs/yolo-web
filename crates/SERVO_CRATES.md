# Consolidated Servo Crates Catalog (`crates/servo-*`)

This document catalogs all **31 consolidated Servo W3C Web Engine crates** in `crates/servo-*` powering the `yolo-web` unified browser monorepo (`yolo-browser` + `obscura` + Bun).

> **Toolchain Purity Guarantee**: Zero Node.js artifacts (`package-lock.json`, `yarn.lock`, `webpack.config.js`, `#!/usr/bin/env node`, or `node:` imports) exist anywhere inside `crates/servo-*`. All JavaScript/TypeScript bridging is handled natively by Bun (`@yolo-web/servo-bridge`).

## Architectural Integration in `yolo-web`

1. **HTML/XML & DOM Pipeline**:
   - `servo-tendril` + `servo-string-cache` + `servo-web-atoms` + `servo-markup5ever` + `servo-html5ever` + `servo-xml5ever` + `servo-rcdom` provide zero-copy W3C HTML5/XML5 parsing directly into `obscura-dom` and `yolo-browser`.
2. **CSS Styling, Selectors & XPath Querying**:
   - `servo-cssparser` + `servo-stylo` (`selectors`, `servo_arc`, `style`) + `servo-xpath` power CSS3/CSS4 selector specificity, right-to-left compound matching, Bloom filter ancestor fast-paths, and XPath 1.0 evaluation.
3. **Layout Geometry, Caching & Media**:
   - `servo-euclid` (`Rect`, `Point2D`, `Size2D`, `Scale`), `servo-smallvec` (`SmallVec`), `servo-uluru` (`LRUCache`), `servo-fnv` (`FnvHashMap`), `servo-svg`, `servo-webvtt`, and `servo-timers` provide deterministic layout math, selector caching, SVG/WebVTT media support, and timer scheduling.
4. **GPU Rendering, Fonts & Process Isolation**:
   - `servo-webrender`, `servo-pathfinder`, `servo-font-kit`, `servo-surfman`, `servo-ipc-channel`, and `servo-gaol` provide GPU display-list compositing, vector/font rasterization, multiprocess IPC, and OS sandboxing.
5. **Bun TypeScript Bridge (`@yolo-web/servo-bridge`)**:
   - `packages/servo-bridge` exposes pure Bun/TypeScript mirrors for `servo-euclid` geometry (`ServoEuclidRect`, `ServoEuclidPoint2D`, `ServoEuclidSize2D`, `ServoViewportScale`), `servo-stylo/selectors` specificity and selector utilities (`ServoSelectorEngine`), `servo-xpath` / `servo-webvtt` parsers, and `SERVO_CONSOLIDATED_CRATES` metadata.
